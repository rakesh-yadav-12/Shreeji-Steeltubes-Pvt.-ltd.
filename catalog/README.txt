CATALOG FILES  (shown in the chat under "Catalog & Technical Details")
Put your PDF / image / Excel files in these folders - they appear in the chat automatically (restart/redeploy the app):

  catalog/catalogue/     -> Company Catalogue
  catalog/datasheet/     -> Technical Datasheet / Size-Thickness Range / Weight Chart
  catalog/certificate/   -> Distribution Certificate
  catalog/awards/        -> Awards & Achievements
  catalog/godown/        -> Gallery -> Godown photos (jpg / png / webp)
  catalog/office/        -> Gallery -> Office photos (jpg / png / webp)

The card title is the file name (underscores become spaces), e.g.  Shreeji_Company_Catalogue.pdf -> "Shreeji Company Catalogue".
You can also upload from Admin -> Documents (those files are lost on hosts with temporary storage, so the folders above are safer).
