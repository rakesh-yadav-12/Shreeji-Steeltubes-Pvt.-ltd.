Admin accounts

Admins log in with their username or mobile number and password. Each admin's password is shown in the table — use Reset to set a new one. Every new enquiry PDF is emailed to each active admin who has an email saved.

Job applications are emailed only to admins whose Job mails switch is On — so they don't go to everyone.

Sales person: switch Sales mails On — that admin gets a mail for every new enquiry saying whether the product is available / not available; when they write the price (button in the mail, or by replying to it) it is sent to the customer automatically.
