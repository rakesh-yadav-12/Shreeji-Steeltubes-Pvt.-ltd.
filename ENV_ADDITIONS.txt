# ---- Google Sheet price/stock auto-reply to the CUSTOMER (new, sheet_quote.py) ----
# The moment a customer submits a product enquiry (and gave an email), the bot looks up their Product + Size
# (+ Thickness, if the sheet has that column) in this Google Sheet and emails them the matching price & stock.
# Uses the same SMTP_* settings above to send the mail - no extra mail setup needed.
#
# Sheet columns required (header row, any order, case-insensitive):  Product | Size | Thickness | Price | Unit | Stock
#
# Setup (one-time, ~5 minutes):
# 1. https://console.cloud.google.com -> create/select a project -> "APIs & Services" -> Library -> enable
#    "Google Sheets API".
# 2. "APIs & Services" -> Credentials -> Create Credentials -> Service account -> any name -> Create and continue -> Done.
# 3. Open that service account -> Keys tab -> Add key -> Create new key -> JSON -> download it.
#    Save the file as  service_account.json  in this project folder (same folder as app.py).
#    IMPORTANT: this file is a secret, like a password - never commit it to git or share it.
# 4. Open the JSON file, copy the "client_email" value (looks like xxx@xxx.iam.gserviceaccount.com).
# 5. Open your Google Sheet -> Share -> paste that client_email -> give it "Viewer" access -> Send.
# 6. Copy the Sheet ID from its URL:  https://docs.google.com/spreadsheets/d/<THIS PART>/edit  -> paste below.
# GOOGLE_SHEET_ID: ONLY the long id from the URL (the part between /d/ and /edit) - NOT the whole link.
